> 🎧 **Brisk** is a fast, simple, and elegant **Text-to-Speech (TTS)** web app built using **Streamlit** and **gTTS (Google Text-to-Speech)**.

With **Brisk**, you can instantly convert text into high-quality natural speech using Google’s TTS engine — right from your browser!

---

## 🚀 Features

- ⚡ **Instant Speech Conversion** — Type text and get speech in seconds  
- 🌍 **Supports Multiple Languages** — Convert text in various supported languages  
- 🎤 **Natural Voice Quality** — Powered by Google Text-to-Speech  
- 🎨 **Clean and Simple UI** — Built with Streamlit for a smooth experience  
- 💾 **Download Option** — Save the generated speech as an audio file (MP3)  
- ☁️ **Cloud-Based** — Requires an internet connection for Google TTS  

---

## 🧠 Tech Stack

| Component | Description |
|------------|-------------|
| **Streamlit** | Framework for building the interactive web interface |
| **gTTS** | Google Text-to-Speech API for voice generation |
| **Python 3.x** | Core programming language |
