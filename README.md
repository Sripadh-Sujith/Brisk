> 🎧 **Brisk** is a fast, lightweight, and offline **Text-to-Speech (TTS)** web app built using **Streamlit** and **pyttsx3**.

With **Brisk**, you can instantly convert any text into natural-sounding speech, customize the voice, adjust speaking rate, and enjoy a clean, minimal interface — all in your browser.

---

## 🚀 Features

- ⚡ **Instant Speech Conversion** — Type text and hear it aloud instantly  
 
- 🗣️ **Voice Customization** — Switch between available male/female voices  
-  
- 🎨 **Clean UI** — Built with Streamlit for a modern, smooth user experience  
- 💾  **Download Speech** — Save generated voice as an audio file  

---

## 🧠 Tech Stack

| Component | Description |
|------------|-------------|
| **Streamlit** | For building the interactive web interface |
| **pyttsx3** | Python library for offline text-to-speech |
| **Python 3.x** | Core programming language |
